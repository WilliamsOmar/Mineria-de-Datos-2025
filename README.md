# Minería de Datos 2025

## 📖 Descripción del Proyecto

Este repositorio contiene los trabajos prácticos, ejercicios y el proyecto integrador (PIA) de la asignatura **Minería de Datos**, cursada durante el año 2025. El objetivo principal es aplicar técnicas de minería de datos a conjuntos de datos reales, utilizando **Python** como lenguaje de programación principal.

## 🎯 Contenido del Curso

El material está organizado por semanas, cubriendo los siguientes temas:

| Carpeta | Tema principal |
|---------|----------------|
| `Week-5` | Estadística descriptiva |
| `Week-6` | Visualización de datos (gráficos) |
| `Week-7` | Pruebas de hipótesis y tests estadísticos |
| `Week-9` | Preprocesamiento y limpieza de datos |
| `Week-10` | Técnicas avanzadas de minería |
| `Week-12` | Modelado y evaluación |
| `Week-13` | Algoritmos de clasificación/clustering |
| `Week-14` | Aplicaciones finales |
| `PIA` | Proyecto Integrador Final |
| `Dataset` | Conjuntos de datos utilizados |

## 📊 Datos Utilizados

Los análisis se realizan sobre el **Archivo de Exoplanetas de la NASA**, disponible en la carpeta `Dataset/`. Este conjunto de datos contiene información astronómica real sobre exoplanetas descubiertos, permitiendo aplicar técnicas de minería a datos científicos.

## 🛠️ Tecnologías y Herramientas

- **Lenguaje**: Python 100%
- **Bibliotecas comúnmente utilizadas** (inferido por el contexto del curso):
  - `pandas` - Manipulación y análisis de datos
  - `numpy` - Cálculo numérico
  - `matplotlib` / `seaborn` - Visualización
  - `scipy` / `statsmodels` - Tests estadísticos
  - `scikit-learn` - Modelos de machine learning
